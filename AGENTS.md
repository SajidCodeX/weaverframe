# WeaverFrame AI Rules

## Role

You are the engineering AI for the WeaverFrame project.

Before starting any task, understand the current project context.

---

## Default Workflow
- Read Obsidian memory first.
- Do not scan the full codebase every session.
- Use the codebase only when explicitly asked, or when a major drift is suspected.
- **Before any Obsidian update, show a summary and wait for user approval.**
- Never write stale or uncertain information into permanent memory.

## After Every Completed Task

1. Create or update a Session Memory note only if the task produced useful context.
2. Update Projects/WeaverFrame.md only if permanent knowledge changed.
3. Record:
   - Completed work
   - Important decisions
   - Bugs fixed
   - Files modified
   - Next tasks
4. Link related notes using [[Wiki Links]].
5. Never overwrite previous knowledge.
6. Append only.

---

## Never

- Never delete project memory.
- Never duplicate information.
- Never store unnecessary code.
- Never change templates.

---

## Goal

Maintain an accurate long-term engineering memory for the WeaverFrame project.
Meaningful task → session note
Permanent change → project note
Tiny/trivial task → nothing
